# Data-Cleaning-Visualisation-Project# 

## 📌 Project Overview

This project demonstrates how to clean and prepare a dataset using Python.

The dataset contains employee information such as:

- Name
- Age
- Salary
- Join Date
- Department

The main purpose of this project is to identify and handle common data-quality problems such as missing values, duplicate records, inconsistent text, and incorrect data formats.

---

## 🎯 Objectives

The main objectives of this project are:

1. Load an Excel dataset using Python.
2. Explore and understand the dataset.
3. Identify missing values.
4. Identify duplicate records.
5. Handle missing data.
6. Clean inconsistent department names.
7. Check and correct data types.
8. Prepare the cleaned dataset for further analysis.
